## 🇹🇷 Türkçe Açıklama

Wordle App, **Ionic** ve **Angular** kullanılarak geliştirilmiş, günlük kelimeleri TDK (Türk Dil Kurumu) API'si üzerinden doğrulayan özel bir Wordle oyunudur. Oyuncular 5 harfli kelimeyi 6 deneme hakkı içinde bulmaya çalışır.

### 🚀 Özellikler

- ✅ TDK API ile kelime doğrulama  
- 🎨 Renkli kutularla harf durumu (doğru/yanlış)  
- 🎉 Doğru tahmin sonrası konfeti efekti  
- 🧠 Türkçe karakter desteği (ç, ğ, ı, ö, ş, ü)  
- ⌨️ Fiziksel ve sanal klavye desteği  
- 📜 Her açılışta rastgele Türkçe kelime seçimi

### 🇬🇧 English Description

Wordle App is a custom Wordle-style game developed using Ionic and Angular, which verifies daily words using the official Turkish Language Association (TDK) API. Players try to guess a 5-letter Turkish word within 6 attempts.

- ✅ Word validation via TDK API 
- 🎨 Colored boxes indicating letter correctness (correct/wrong)
- 🎉 Confetti animation when the correct word is guessed  
- 🧠 Full support for Turkish characters (ç, ğ, ı, ö, ş, ü)  
- ⌨️ Support for both physical and on-screen keyboard
- 📜 Random Turkish word selected on each game start
